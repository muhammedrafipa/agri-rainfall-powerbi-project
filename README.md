# Agricultural Rainfall & Productivity Dashboard

## Overview
This Power BI project analyzes rainfall patterns and their impact on agricultural productivity across Indian states.

## Objectives
- Analyze temporal rainfall trends across regions
- Evaluate the correlation between rainfall and crop yields
- Identify seasonal and geographic variations in agricultural productivity
- Build an interactive Power BI dashboard for insights

## Tools Used
- Power BI
- Power Query
- DAX
- GitHub

## Dashboard Pages
### 1. Overview Dashboard
- KPI metrics
- Key insights and recommendations
- Rainfall trends and productivity summary

### 2. Temporal Rainfall Trends
- Yearly rainfall trend analysis
- State-wise rainfall distribution
- Monthly rainfall comparison

### 3. Rainfall vs Crop Yield
- Rainfall and rice yield correlation
- Crop yield comparison across states
- Rainfall category analysis

### 4. Seasonal & Geographic Analysis
- Geographic rainfall distribution
- Seasonal rainfall contribution
- Regional rainfall patterns

## Key Insights
- Kerala and Assam recorded the highest rainfall levels.
- Higher rainfall does not always guarantee higher crop yield.
- July and August contribute the highest seasonal rainfall.
- Significant regional variations exist in agricultural productivity.
